# 个人 Mac 桥接

本项目的个人测试方案：iPhone App → 你配对的 Mac（HTTPS）→ 官方 Codex CLI → OpenAI。AI 教练针对本次问题生成文字、引用汇总记录并提出追问；电量分数继续由本地模型计算。没有读取或复制 Codex OAuth 凭证，不使用付费 API 回退，也没有自动 Reset。

Mac 必须在线、保持可被手机访问，Codex 必须以你自己的 ChatGPT 账号登录。使用会计入订阅限额；CLI 额度、网络或模型不可用时会明确失败。离开 Mac 所在网络后，本方案不保证可连接，不等同于随时随地可用的正式服务。

## 启动与配对

要求 Python 3、OpenSSL 和已安装的官方 `codex`。先自行运行 `codex login` 完成官方登录。只用 `codex login status` 核对登录方式，不读取凭证文件。

默认仅本机监听，适合模拟器测试：

```sh
python3 Integration/CodexBridge/bridge.py
```

程序把连接凭证、证书、私钥和配对信息保存到 `~/Library/Application Support/RecoveryPocketBridge`。目录权限 700，敏感文件 600；不会把连接凭证打印到终端。配对文件 `pairing.json` 是敏感信息，请只复制到自己的手机，不发到聊天、仓库或报告。

同一局域网真机连接需要显式启动：

```sh
python3 Integration/CodexBridge/bridge.py --listen 0.0.0.0
```

这会允许能到达该 Mac 的设备尝试连接；每次请求仍必须持有随机配对凭证，并通过 HTTPS。不要添加公网端口映射。若 Mac 的实际 Bonjour 名称与默认 hostname 不同，可用 `--hostname Your-Mac.local` 指定；主机名必须包含在证书 SAN 内，修改名称或证书后要重新生成并重新配对。

手机进入「我的 → AI 接入与自检」，粘贴 Mac 配对信息并保存，再点「测试 Mac 连接（合成数据）」。首次本地网络权限由你确认。配对只信任这台 Mac 的精确证书和主机名，不需要关闭 iOS 安全保护或安装系统根证书。

到「今天 → AI 健康教练」输入问题。App 先展示本次问题、摘要、缺失项、本地参考与发送地址；你确认后才发送。经 Mac 的摘要会继续交给 OpenAI，不能叫作完全本地 AI。问题中主动输入的个人信息也会发送。

自动云端晨报默认关闭；它和每次确认的教练问答分开。配对会关闭自动晨报；若主动开启，首页可自动发送候选晨报中的健康数值。API Key 与 Mac 连接凭证只在手机钥匙串内，并绑定到保存时的完整请求地址；地址变更后需重新保存或配对，不把旧凭证转发到另一个地址。正式多人发布时，模型服务商密钥应留在受控后端。

## 限制

- 当前为个人试用桥接，没有公网托管、服务保活或远程唤醒；不会自动修改 Mac 的睡眠设置。
- 默认自签名证书有效期 30 天；轮换证书需重新配对。不要在旧手机配对仍生效时悄悄替换信任对象。
- CLI 运行在单次临时目录、只读权限；不加载用户配置、AGENTS 项目说明、插件、App、记忆或技能，禁用 shell、执行工具、浏览器、图像生成和代理协作。提示通过标准输入传递，不拼接到 shell。
- 一次只处理一个请求，超时终止本次子进程。CLI 的可恢复错误事件不是工具调用；只有成功退出且有最终 JSON 才接受结果。实际工具事件会拒绝展示。
- 不记录问题、摘要、回答或授权头；订阅服务商仍按其产品政策处理请求，不能保证服务商不留存。临时输出由临时目录清理。
- 引用存在性、格式与数量检查不是医学事实核验；AI 的解释可能有误。数值从原始摘要卡渲染，AI 文本不新增测量值、不修改健康记录或模型。

## 后续接入选项（2026-10-15 核对）

OpenAI 现已提供官方 [Sign in with ChatGPT](https://developers.openai.com/siwc/quickstart)，合资格的 Plus/Pro 用户可授权适用的开源、本地个人项目使用订阅额度，并非所有 App 登录后都自动获得推理权限。[官方本地示例](https://developers.openai.com/cookbook/articles/sign-in-with-chatgpt)使用动态客户端注册、PKCE 和回环回调。

这提供了比长期依赖 CLI 更合适的升级路径，但本轮尚未验证本项目 iPhone 原生回调、账号授权范围与可用模型，也没有复用现有 Codex token 来冒充新 App 授权。当前可验收的是上面的个人 Mac 桥接。未来独立手机方案应先评估官方授权，再按需要接服务端 API。

Claude 的官方说明也已更新：[2026-10-07 说明](https://support.claude.com/en/articles/15036540-use-the-claude-agent-sdk-with-your-claude-plan)涉及订阅、Agent SDK 与部分计划的 API credits；具体以账号计划为准。本机未安装 Claude CLI，本轮没有伪称已接入它。

依据：[Codex 登录方式](https://learn.chatgpt.com/docs/auth)、[非交互运行](https://learn.chatgpt.com/docs/non-interactive-mode)、[OpenAI 生产密钥管理](https://developers.openai.com/api/docs/guides/production-best-practices)、[Apple Foundation Models](https://developer.apple.com/foundation-models-framework/)。本地模型是否可用以设备实际报告为准，不能只根据 iPhone 型号判定。
